# Compass

*New Version Release includes more covers* *  
  
A simple compass application for Android, made with Unity game IDE. Aside from the North indicator, the compass has randomized gauges with multiple indicators: centre, middle and external ones. 

  ![alt text](https://github.com/RgbTrouw/Compass/blob/root/Compass8.png)  
  

It suggests some functions of a poligraph application.  
"The human body interferes with radio waves by absorbing, reflecting, and scattering them (...)." - Google Search
  
Different gauges might signify different things.  
  
The latest version has a cover on some of the indicators.   
  
The cross design of the cover is an arch bolt as viewed from the side.  
  

The PC version of the program always shows North 0 degrees and could serve as reference for a cover template, similar to the earth's meridian and longitudinal lines model.  
  
(It also looks a bit like audio speakers as viewed from the back)
