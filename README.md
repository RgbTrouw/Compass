# Compass

A simple compass application for Android. Aside from the North indicator, the compass has other gauges with multiple indicators: centre, middle and external ones. 


It suggests some functions of a poligraph application as well. "The human body interferes with radio waves by absorbing, reflecting, and scattering them (...)." - Google


** The latest version has a cover on some of the indicators. (See "Compass8.png")  
  
(The +/- cross design is an arch bolt as viewed from the side.)

The pc version always shows North 0 degrees and could serve as reference template.
