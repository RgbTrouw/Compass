# Compass

A simple compass application for Android. Aside from the North indicator, the compass has other gauges with multiple indicators: centre, middle and external ones. 


It suggests some functions of a poligraph application.  
"The human body interferes with radio waves by absorbing, reflecting, and scattering them (...)." - Google Search


The latest version has a cover on some of the indicators. (See "Compass8.png")  
  
The cross design of the cover is an arch bolt as viewed from the side.  
  

The PC version of the program always shows North 0 degrees and could serve as reference template for a cover template, similar to the meridian and longitudinal lines model.  
  
It also looks like some audio speakers as viewed from the back.
